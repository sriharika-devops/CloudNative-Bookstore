# ☁️ CloudNative-Bookstore

An end-to-end **Cloud DevOps Project** demonstrating CI/CD, container orchestration, monitoring, and security best practices using **AWS, Jenkins, Docker, Kubernetes, Prometheus, and Grafana**.

---

## 🚀 Project Overview
This project simulates a **Bookstore microservice application** deployed on AWS using a fully automated DevOps pipeline.

The goal is to showcase:
- CI/CD automation using **Jenkins** and **GitHub Actions**
- Containerization with **Docker**
- Deployment orchestration using **Kubernetes (EKS)**
- Monitoring with **Prometheus + Grafana**
- Security scanning using **SonarQube + Trivy**
- End-to-end cloud deployment on **AWS**

---

## 🧩 Architecture

![Architecture Diagram](docs/architecture-diagram.png)

**Tech Stack:**
- **Cloud:** AWS (EC2, S3, ECR, IAM, ELB)
- **CI/CD:** Jenkins, GitHub Actions
- **Containers:** Docker, Kubernetes, Helm
- **Monitoring:** Prometheus, Grafana
- **Security:** SonarQube, Trivy
- **Language:** Python (Flask) or Node.js (Express)

---

## ⚙️ Features
- Fully automated build → test → deploy → monitor pipeline
- Blue-Green deployment strategy
- Real-time application monitoring dashboards
- Vulnerability scanning for code and container images
- Easy rollback and scalability setup
